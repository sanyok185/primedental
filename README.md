# Prime Dental — статичний сайт (HTML + CSS + JS)

Концепт для портфоліо. Без збірки й залежностей: відкрийте `index.html` у браузері
або завантажте всю папку на будь-який хостинг (Netlify, Vercel, GitHub Pages, звичайний хостинг).

## Сторінки
index.html · services.html · service-treatment.html · doctors.html · about.html · contacts.html · booking.html

## Структура
- css/style.css — усі стилі; змінні кольорів і шрифтів на початку файлу. Брейкпоінти: 1000 / 860 / 640 px.
- js/main.js — мобільне меню, липка шапка, поява блоків при скролі, лічильники цифр. Анімації вимикаються, якщо в системі ввімкнено «зменшити рух».
- js/booking.js — форма запису (3 кроки, валідація, підтвердження, .ics).
- img/ — оптимізовані фото.

## Що треба підключити
1. Форма запису: у js/booking.js змінна ENDPOINT (на початку файлу). Поки порожня — заявка нікуди не йде (демо).
   Підійде Formspree, Telegram-бот, свій бекенд.
2. Мапа — заглушка. Замініть блок `.map` на iframe Google Maps.
3. Телефон: +380 67 372 12 32 (пошук по `380673721232` та `372 12 32`).
4. Соцмережі та політика конфіденційності — посилання-заглушки `#`.
5. Шрифти підтягуються з Google Fonts.
